## Purpose

Defines requirements for a high-craft, visual-first skills section representing the developer's core tech stack accurately and attractively.

## ADDED Requirements

### Requirement: Accurate and comprehensive tech stack data
The portfolio data SHALL list all core technologies matching the developer's CV and reference materials, categorized logically into Frontend, Backend & APIs, and DevOps & Tools.

#### Scenario: Displaying verified skills
- **WHEN** the visitor scrolls to the skills section
- **THEN** technologies such as JavaScript, TypeScript, Python, FastAPI, React, Next.js, Redux, Node.js, Express, PostgreSQL, Docker, Tailwind, Sass, HTML, and CSS are prominently displayed.

### Requirement: Visual-first card layout
The skills section SHALL use a polished, card-based visual layout with distinct category groupings and interactive hover effects.

#### Scenario: Interacting with skill cards
- **WHEN** the visitor hovers over skill items or category cards
- **THEN** subtle visual elevation, border highlighting, or glow effects occur without layout shifting.
