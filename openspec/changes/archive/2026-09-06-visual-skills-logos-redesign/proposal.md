## Why

The previous text/pill badge design for skills lacks the rich visual branding and icon representation seen in professional developer portfolios. The user explicitly requested a more visual approach featuring authentic technology logos/icons matching their reference image.

## What Changes

- Add authentic vector logo/icon components for each core technology (JavaScript, TypeScript, Python, FastAPI, React, Next.js, Redux, Node.js, Express, PostgreSQL, Docker, Tailwind CSS, Sass, HTML5, CSS3) in `src/components/ui/Icons.tsx`.
- Redesign `src/components/sections/Skills.tsx` into a high-craft visual grid featuring technology cards with authentic brand logos, brand-colored accents, and polished glassmorphic/dark elevation.

## Capabilities

### New Capabilities
- `logo-skills-grid`: A visual-first tech stack grid featuring authentic brand vector logos and polished card containers for each technology.

## Impact

- Affected files: `src/components/ui/Icons.tsx`, `src/components/sections/Skills.tsx`.
- Visual impact: Replaces text badges with high-fidelity branded tech icons matching the user's reference visual world.
